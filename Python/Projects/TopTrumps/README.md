# TopTrumps

TopTrumps is a CoderDojo Portarlington application aimed at having fun while learning the fundamentals of programming with Python.

## Installation
Before installation you need to ensure setuptools and wheel are istalled: 
```bash
python -m pip install -U pip setuptools wheel
```
Next run the following from project root.
```bash
python -m pip install .
```

## Usage
To run the application:
```bash
python -m toptrumps.top_trumps
```
